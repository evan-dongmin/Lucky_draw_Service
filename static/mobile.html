🎯 예측 게임

📖 어떤 게임인가요? (30초 설명)

3라운드 서바이벌 카트 레이스입니다. 라운드마다 하위권 카트가 탈락하고, 여러분은 라운드가 시작되기 전에 결과를 예측해 점수를 모읍니다.

라운드마다 무엇을 고르나요?

라운드고르는 대상맞히는 것
1라운드 부서(팀) 하나 어느 부서가 통과율 1위일까?
2라운드 부서(팀) 하나 살아남은 부서 중 통과율 1위는?
결선
배점 3배		 카트(개인) 하나 결선 진출자 중 1등은 누구?

정답에 가까울수록 점수가 큽니다 — 고른 대상이 1위면 100%, 2위 60%, 3위 35%… 순위 밖이어도 참여 점수 5%가 들어옵니다. 내 부서를 골라도 되고, 이길 것 같은 다른 부서를 골라도 됩니다.

🎯 직접 고르면 예측 점수가 40% 더 붙습니다. 안 골라도 자동 배정으로 점수는 그대로 들어오지만, 직접 고른 사람이 그만큼 앞서 나갑니다.

참여 방법

  1. 부서·이름 선택 — 내가 누구인지 알려주세요
  2. 내 카트 선택 — 카트마다 예측 점수 특성이 다릅니다
  3. 라운드마다 예측 — 라운드 시작 전에 하나만 고르면 끝
  • 🎯 빗나가도 0점이 아닙니다 — 참여 점수가 항상 들어옵니다
  • 🏁 1·2라운드는 순위뿐 아니라 1등이 결승선을 통과한 뒤 10초/5초 안에 들어와야 통과합니다 — 순위권이어도 너무 늦으면 탈락하니 "내 카트 현황"을 계속 확인하세요
  • 💥 장애물에 부딪히면 실제로 순위가 밀립니다 — 연출이 아니라 진짜 결과입니다. 콘🚧은 살짝 휘청하는 정도지만 폭탄💣·바위🪨에 맞으면 거의 멈춰 서서 뒷차들이 지나갑니다 (멈춘 뒤에는 다시 속도를 올려 따라붙습니다)
  • 🏆 최종 점수 상위권이 실제 경품 당첨자입니다 (결선 배점이 3배라 끝까지 뒤집힙니다)
  • 🔒 레이스 결과(장애물·결승선 컷오프까지 전부)는 시작 전에 이미 시드 하나로 확정돼 있어 아무도 조작할 수 없습니다

1. 부서를 선택하세요

2. 본인 이름을 선택하세요

3. 내 카트의 특수능력을 선택하세요

고르지 않아도 소속 부서 기준으로 자동 배정됩니다. 언제든 바꿀 수 있어요.
