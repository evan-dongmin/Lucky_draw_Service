연결 대기 중...

  1. 명단 등록 — 아래에 참가자 명단을 붙여넣거나 파일을 올리고 미리보기로 확인하세요.
  2. 세션 생성 — 당첨 인원수·진행 시간을 확인하고 세션을 만드세요.
  3. 커밋 생성 → 레이스 시작 — 순서대로 눌러야 진행됩니다(먼저 커밋해야 레이스를 시작할 수 있어요).
  4. 필요할 때만 재추첨·초기화·조기 종료 버튼을 사용하세요.

1. 참가자 명단

오늘 행사의 추첨 대상 명단입니다. 붙여넣기/파일 업로드/샘플 생성 중 하나로 채운 뒤, 반드시 미리보기로 내용을 확인하세요.

2. 세션 생성

명단 미리보기를 마쳤다면 당첨 인원수와 진행 시간을 정하고 세션을 생성하세요.

참여형 예측 게임은 항상 켜져 있습니다 -- 무손실입니다 -- 확신도 100점을 세 라운드에 나눠 걸고, 빗나가도 차감이 없습니다. 순위가 가까울수록 점수가 크고 참여만 해도 최소 점수가 들어가므로, 첫 라운드에 빗나간 참가자도 끝까지 역전을 노릴 수 있습니다.

3. 진행

세션 없음

특정 인원을 이번 추첨에서 빼려면 아래에 사번을 적고 적용하세요(생략 가능).

① 커밋으로 결과를 미리 봉인·공개하고, ② 레이스 시작으로 진행을 시작하세요.

무대 화면 카메라는 라운드별로 자동 전환됩니다 — 수동으로 바꾸고 싶을 때만 아래 버튼을 누르세요. 진행이 밀리면 조기 종료(비상) 버튼을 쓸 수 있습니다.

레이스가 끝난 뒤 다시 뽑고 싶으면 재추첨을, 처음부터 다시 시작하려면 전체 초기화를 누르세요(초기화는 되돌릴 수 없습니다).
